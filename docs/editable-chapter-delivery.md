## 调用与边界

从项目根执行，默认只检查并规划：

```powershell
python plugins/jed-video-system/scripts/editable_chapter_delivery.py --props work/chapter-insert/20261001-r2/props.json --review-state work/chapters/review-state-insert-r2.json --candidate-id chapter-insert-sound-sample-r2 --job-id 20261001-r4
```

加 `--execute` 拆分透明MOV、提取原声并创建隔离草稿；再加 `--publish` 经现有Bridge的进程检查、备份与首页事务登记新工程。剪映正在运行时先完成副本，用户保存并正常退出后再登记；不自动关软件。失败保留job与日志，不用原job自动重跑副作用；同一成功版本可复用，产物或输入变化需新job-id。

此入口只针对未手调、已确认的30fps paper-blue r1插入试验，不是任意精修工程迁移器。核验audio_sample的真实批准、精确props及递归媒体/实现依赖，输出wholeVideoApproved=false。旧visual_sample或一个“风格满意”字段不能替代新增声音与停顿的实际确认。

`jed_chapters.editable`负责批准和透明块源时钟映射；`workers/draft-adapter/inserted.py`负责分轨与已保存内容检查；`publish_inserted.py`只通过既有Bridge验证/登记。CLI负责受控调用、输入和实现摘要、日志与执行回执。没有修改ChatCut或Remotion官方插件，也没有另写codec或MCP服务。

## 值得记住的交接细节

原PNG为1672×941，保留该原图，通过原生缩放关键帧适配画布；不要求为了导入先重做一张1920×1080的生成图片。暖白底独立一层，图片淡入淡出仍有底色。原生文字使用独立字号和位置映射、轻入场/退场及位移关键帧；其像素排版与动画资源加载仍需剪映UI核查，没有把未播放的工程描述成与Remotion逐像素一致。

在当前固定fork中，普通TextSegment只传font_path不会完整写出字体引用。通过已有style_ranges API给原生文字设置真实本地字体路径，调用已有inline_materials把字体复制进工程；保存与发布后逐样式检查字体文件实际存在。未修改第三方库。

AAC源音频比视频尾部短约十几毫秒，分离原声后按视频帧数补齐末尾静音，只补缺失尾部，不删除/拉伸语音。拆分透明MOV使用源帧区间再将片段时钟归零；移动到插入后的输出位置，内部原有cue不重算。Alpha抽样验证透明角落、可见内容及末帧全透明。

当前Bridge的neutral验证统计added_sound_effects=0，因为全部11轨在基础草稿中已完成，它没有再添加音效。实际工程中仍有一条短音效轨与1个声音片段，已由独立分轨检查及MCP确认；不拿中间事务统计冒充成片轨道数量。

170项行为测试通过，覆盖批准范围、依赖变化、原始分辨率PNG、源/输出映射、分轨数量、文字和字体保存、声音分离等。从发布后的真实原声/音效路径和区间重建音轨，6处语音窗口及音效区间相关性均接近1，时钟偏移0。这是文件时间映射校验，未在剪映原生导出。
