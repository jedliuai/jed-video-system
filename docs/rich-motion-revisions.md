# 在手工剪辑之后升级视觉

用户在剪映中保存过修改后，剪映最新主时间线就是继续编辑的依据。不要从最初生成的时间表重新搭建工程。多时间线项目先读取 `Timelines/project.json` 的主时间线，再选择最新的实际内容；旧 `draft_info.json` 可能仍保留初稿。

## 小范围改动与保留检查

制作新副本，允许的改动逐项列明：更换指定动效素材路径、追加不重叠的动效片段、调整指定章节标题的文字/字号/位置。原主画面、字幕、声音和旧动效片段的剪切点、源偏移、速度、变换、关键帧与未知字段必须保留。

检查时撤销这份白名单中的变化，要求其余工程内容与最新保存版本完全一致。这项检查独立于 Bridge 的副本传输检查：后者只能证明已修改的基线正确传入新副本，不能证明用户编辑被保留。

保存后的原生文件可能省略零起点、默认速度或轨道索引。读取时采用默认值，不应为了校验把这些字段写回原工程。主片源切点使用实际微秒时间与每段保存的速度；只在输出显示时映射到视频帧。

## 有内容依据的丰富动效

入口：`motion-lab/src/trade/TradeRichEntry.tsx` 与 `TradeScreenEntry.tsx`，使用本机 Remotion CLI。官方 Remotion 与 ChatCut 插件作为外部能力调用，不修改它们的内部实现。

口播可采用多种结构：图标角色卡、成本分支关系图、带角框的部署路径、并列工具矩阵、源码获取步骤。蓝、青、金、紫分别强调节点，避免把不同类型的内容都画成同一种卡片。并列工具不应画成依赖链；具体报价金额只使用实际视频出现的示例。

用户授权增加彩色边框时，可以在透明画面上使用细框。文字保持无白色描边、光晕和阴影。图标、框线与节点按照原声语义出现；字体加载后测量节点内容，过长文字应换行或重排。不能靠裁切隐藏溢出。

录屏提示放在已有上方留白，必要时给实际控件加四角框，不盖住输入值、结果、鼠标或人物小窗。框选必须对照本片实际源帧；页面会滚动时缩短范围或仅保留顶部提示。导出表格可强调表头，而无需再画一张遮住真实结果的表格。

## 章节与透明素材

章节标题与背景图片分开保留。长标题明确拆为自然的两行，限定在左侧安全区；右侧图案单独保护。保留用户已有的章节时长、图片动画、无口播停顿与短转场音效。字幕和所有动效仍在可编辑轨道上。

每次重做动效从新 PNG 序列编码一次，使用新素材路径。剪映的透明合成采用已验证的预乘 alpha 运输方式；禁止在旧透明 MOV 上反复转换。已有动效被用户切成多段时，替换完整母版并保留各段源偏移，不能让每段都从动画第一帧开始。

## 预览与登记

审阅预览需要使用手工版本的全部主片段、原字幕文字与时间、原音效片段以及动效源偏移。不要为了输出预览重新添加原生工程中不存在的音频淡入淡出。

先完成隔离候选与检查，再请用户保存并正常退出剪映。登记前重新读取原工程：如果用户又保存了修改，应将候选重建到新的基线。不得自动关闭剪映或覆盖用户的原草稿。预览渲染、结构校验和实际剪映播放是不同证据，交付时分别说明。
