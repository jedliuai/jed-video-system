# 报价工作台口播动效

这组组件把口播信息组织成报价关系图、AI 实现流程、适用人群和获取源码路径。沿用 Jed 已确认的原画面直接叠元素：纯色文字，无面板、文字描边、阴影或光晕。

`TradeReviewEntry.tsx` 是独立 Remotion 入口，不依赖主项目 Root 的注册。`TradeReview` 在浏览器栅格化前将 1920×1080 的设计坐标缩放为 2560×1440；`TradeFocus` 是可选的原生录屏定位框，本次首版整片没有加入定位框。

输入 `TradeOverlayProps` 的 durationInFrames 与节点 cue 必须来自实际剪切、变速和章节插入后的统一时间线。示例的零帧 cue 只用于排版检查。全片分段透明素材可以共用一条动效轨道，前提是片段不重叠。

建议输出新 PNG 序列，再使用仓库 `scripts/encode-jianying-alpha.py` 编码新路径的 ProRes 4444。编码器将 RGB 预乘 alpha，显式未知标签阻止 FFmpeg 再次自动转换。预览合成必须显式使用 premultiplied alpha；不能把旧 MOV 再预乘一次。普通播放器合成正常仍需剪映实际播放确认。

首次批量应用新布局或音效节奏前，展示含真实口播、字幕、原画面的短视频并记录用户对这一版的答复。录屏默认保留真实 UI，不自动铺 B-roll。公开仓库只放可复用代码和流程记录，个人原视频、逐字稿、缓存帧和本机工程保留在对应视频项目目录。
