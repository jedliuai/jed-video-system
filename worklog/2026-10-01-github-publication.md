# 把当前原型同步到公开 GitHub 仓库

## 做了什么

在项目根建立总 Git 仓库，使用已有 GitHub 登录账号 jedliuai，创建公开仓库 https://github.com/jedliuai/jed-video-system，以 main 保存当前源码、插件原型、Remotion 组件、配置模板、Schema、测试、设计说明和已有工作总结。README 补充了仓库地址、基础检查入口，以及克隆后需要自行准备的素材和运行环境。

## 为什么做

前两轮已经积累了可复用模块，需要一个统一的版本入口，方便后续继续拆分开发、回看决策和同步工作。公开内容要让别人看清系统现在做到了哪里，也要说明本机样片成功并不代表整个插件已经可以跨机器直接安装。

## 值得记住的决策和坑

原始个人素材、第三方参考图和视频、字体、生成视频、转录缓存、实际剪辑计划、本地配置及 agy 原始调用日志都留在本机。只公开配置模板、可读设计说明和源码；上线前按待提交文件检查了常见凭据格式，没有发现匹配。

motion-lab 原先有独立的本地 Git 仓库。没有删掉或移动它的历史，而是把当前文件作为总仓库里的普通目录保存，并确认没有 gitlink。否则总仓库看起来包含这个目录，实际克隆时却可能拿不到组件代码。

中文和含空格的文件路径不能直接拿 Git 的默认带引号输出做集合比较；这次用 UTF-8 和 NUL 分隔路径来核对忽略列表，避免误把素材算进公开文件。提交身份只在当前项目设置，使用 GitHub noreply 邮箱，不改全局 Git 配置。

发布前重跑 49 项行为测试及 Remotion ESLint / TypeScript 检查，全部通过。剪映应用播放、透明效果与保存重开仍属于待验证项，本次同步不改变这些验收状态。

## 一句话亮点

把本机跑通的视频制作原型放进统一公开仓库，让视觉、时间计划和剪映适配开始拥有可追溯的版本。
